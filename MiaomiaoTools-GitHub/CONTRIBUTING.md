# 贡献指南

## 开发环境

推荐使用 Python 3.11，并在独立虚拟环境中安装 `requirements-dev.txt`。

提交代码前请运行：

```powershell
python -m pytest -q
```

## 修改原则

- 图像识别修改需要附带真实截图回归用例。
- 新增地图模板时，需要同时检查节点数、边数、起点、终点和固定节点。
- 新增节点类型时，需要同步维护 `data/rules` 中的类别、距离和生成上限。
- 不要提交 `build`、`dist`、虚拟环境、缓存或个人调试输出。
- 不要在源码中写入个人绝对路径。

## 问题报告

识别问题应尽量包含以下信息：

- 游戏层数；
- 原始完整截图；
- 设备分辨率和截图尺寸；
- 预期节点类型或基底；
- 实际识别结果。
